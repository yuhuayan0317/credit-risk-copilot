# 数据字典

数据库为 DuckDB，包含 3 张表：`loans`（用户放款与还款明细）、`risk_scores`（模型评分）、`shap_values`（模型归因）。三张表通过 `user_id` 关联。

## 表 loans：用户放款与还款明细

每行一个用户，共 30,000 行，放款月份覆盖 2025-01 至 2025-12。

### 业务维度字段

| 字段 | 类型 | 含义 | 取值 |
|---|---|---|---|
| user_id | INTEGER | 用户唯一标识 | 1 ~ 30000 |
| loan_month | VARCHAR | 放款月份（cohort），格式 YYYY-MM | 2025-01 ~ 2025-12 |
| channel | VARCHAR | 获客渠道 | APP自然流量 / 信息流广告 / 合作方导流 / 线下门店 |
| city_tier | VARCHAR | 城市等级 | 一线 / 二线 / 三线及以下 |

### 用户属性字段

| 字段 | 类型 | 含义 | 编码说明 |
|---|---|---|---|
| credit_limit | DOUBLE | 授信额度（元） | 10,000 ~ 1,000,000 |
| sex | INTEGER | 性别 | 1=男，2=女 |
| education | INTEGER | 学历 | 1=研究生，2=本科，3=高中，4=其他；0/5/6 为未定义编码，见《数据质量规则》 |
| marriage | INTEGER | 婚姻状况 | 1=已婚，2=单身，3=其他；0 为未定义编码 |
| age | INTEGER | 年龄（岁） | 21 ~ 79 |

### 还款行为字段（观察期 6 个月，后缀 1 表示距观察点最近的一个月）

| 字段 | 含义 |
|---|---|
| pay_status_1 ~ pay_status_6 | 第 k 个月的还款状态。-2=当月无消费；-1=按时全额还款；0=使用循环信用（只还了最低还款额，未逾期）；1~8=逾期 1~8 个月（9 表示 9 个月及以上） |
| bill_amt_1 ~ bill_amt_6 | 第 k 个月的账单金额（元）。可能为负数，表示用户多还款形成的溢缴款 |
| pay_amt_1 ~ pay_amt_6 | 第 k 个月的实际还款金额（元） |

注意：pay_status_1 是最近一个月，pay_status_6 是最早的一个月。

### 标签字段

| 字段 | 含义 |
|---|---|
| is_bad | 坏账标签。1 = 表现期内发生违约（坏用户），0 = 正常。坏账率即 is_bad 的均值，口径见《指标口径》 |

## 表 risk_scores：模型评分

| 字段 | 类型 | 含义 |
|---|---|---|
| user_id | INTEGER | 用户 ID |
| risk_score | DOUBLE | XGBoost 模型预测的违约概率，0 ~ 1 |
| risk_level | VARCHAR | 风险等级：高（risk_score ≥ 0.5）/ 中（0.25 ≤ risk_score < 0.5）/ 低（< 0.25） |
| dataset | VARCHAR | 该用户在模型训练时所属的数据集：train / valid / test。**评估模型效果（AUC、KS）时只能用 dataset = 'test' 的用户**，否则会因为包含训练样本而高估效果 |

## 表 shap_values：模型归因（长表）

| 字段 | 类型 | 含义 |
|---|---|---|
| user_id | INTEGER | 用户 ID |
| feature | VARCHAR | 模型特征名（共 27 个，见《模型说明》） |
| shap_value | DOUBLE | 该特征对该用户预测结果的 SHAP 贡献，单位为 log-odds。正值推高违约风险，负值降低违约风险 |

每个用户有 27 行（每个特征一行），共 810,000 行。做群体归因时，先按特征分组求平均 SHAP，再对比两个群体的差异。

## 常用 SQL 示例

```sql
-- 按渠道和月份统计坏账率
SELECT channel, loan_month, COUNT(*) AS n, AVG(is_bad) AS bad_rate
FROM loans GROUP BY channel, loan_month ORDER BY channel, loan_month;

-- 关联模型评分
SELECT l.channel, AVG(r.risk_score) AS avg_score
FROM loans l JOIN risk_scores r USING (user_id) GROUP BY l.channel;

-- 某群体的平均 SHAP（按特征）
SELECT s.feature, AVG(s.shap_value) AS mean_shap
FROM shap_values s JOIN loans l USING (user_id)
WHERE l.channel = '信息流广告' AND l.loan_month >= '2025-10'
GROUP BY s.feature ORDER BY mean_shap DESC;
```
