# 指标口径

本文档是风险分析指标的唯一口径来源。分析报告中的所有指标必须按本文档计算；如需偏离口径，必须在报告中显式说明。

## 坏账率（Bad Rate）

- **定义**：某群体中坏用户（is_bad = 1）的数量 ÷ 该群体的用户总数。
- **SQL**：`AVG(is_bad)` 或 `SUM(is_bad) * 1.0 / COUNT(*)`
- **展示**：以百分比展示，保留 1 位小数，例如 22.1%。
- **按月口径**：「某月坏账率」指 loan_month 为该月的放款 cohort 的坏账率（vintage 口径），不是该月发生的违约数。
- **按季度口径**：Q1 = 01~03 月，Q2 = 04~06 月，Q3 = 07~09 月，Q4 = 10~12 月；季度坏账率 = 该季度所有放款用户的坏账率（按用户加权，不是月度坏账率的简单平均）。

## 坏账率变化的表述

- **百分点（pp）**：两个坏账率的差，例如 20.0% → 28.0% 表述为「上升 8.0 个百分点」。
- **相对变化**：(新 - 旧) / 旧，例如 20.0% → 28.0% 为「相对上升 40%」。
- 报告中优先使用**百分点**，避免混淆。

## 坏账率异动的判定标准

满足以下全部条件，才判定为「显著异动」：

1. 与对照期（默认是该维度前 3 个月的平均值，或全年其他月份）相比，变化幅度 ≥ 3 个百分点；
2. 异动群体样本量 ≥ 300；
3. 两比例 z 检验 p 值 < 0.05。

样本量不足 300 的群体，其坏账率波动可能由随机性导致，报告中必须注明「样本量不足，结论仅供参考」。

## 逾期率

- **当前逾期率**：pay_status_1 ≥ 1 的用户占比（最近一个月处于逾期状态的用户比例）。
- **历史逾期率**：近 6 个月中任一月 pay_status ≥ 1 的用户占比。
- **M2+ 逾期**：pay_status ≥ 2，即逾期 2 个月及以上。

## 额度使用率（Utilization）

- **定义**：bill_amt_1 ÷ credit_limit（最近一期账单金额 ÷ 授信额度）。
- 高使用率（≥ 80%）通常意味着资金紧张，是风险信号。
- bill_amt_1 为负时，使用率记为负值，含义是溢缴款，不代表风险。

## 高风险用户占比

- **定义**：risk_level = '高'（即 risk_score ≥ 0.5）的用户数 ÷ 群体总用户数。
- **平均风险分**：AVG(risk_score)，即模型预测的平均违约概率，可与实际坏账率对比来检验模型校准情况。

## 标准分层口径

做用户分层时，必须使用以下标准分箱，保证不同报告之间可比：

### 年龄段
| 分段 | 规则 |
|---|---|
| 25岁及以下 | age ≤ 25 |
| 26-30岁 | 26 ≤ age ≤ 30 |
| 31-40岁 | 31 ≤ age ≤ 40 |
| 41-50岁 | 41 ≤ age ≤ 50 |
| 50岁以上 | age > 50 |

### 授信额度段
| 分段 | 规则 |
|---|---|
| 3万及以下 | credit_limit ≤ 30000 |
| 3-5万 | 30000 < credit_limit ≤ 50000 |
| 5-10万 | 50000 < credit_limit ≤ 100000 |
| 10-20万 | 100000 < credit_limit ≤ 200000 |
| 20万以上 | credit_limit > 200000 |

### 客群标签
| 客群 | 规则 |
|---|---|
| 年轻低额度客群 | age ≤ 30 且 credit_limit ≤ 50000 |
| 近期逾期客群 | pay_status_1 ≥ 1 |
| 循环信用客群 | pay_status_1 = 0 |
| 优质客群 | 近 6 个月 pay_status 全部 ≤ 0 且 credit_limit > 100000 |

## 模型区分度指标

- **AUC**：ROC 曲线下面积，0.5 为随机，越接近 1 越好。信贷评分卡一般 0.70 以上可用，0.75 以上良好。
- **KS**：好坏用户累计分布的最大差值，一般 0.3 以上可用。
- **PSI（群体稳定性指标）**：衡量两个群体的分数分布差异。PSI < 0.1 稳定；0.1 ~ 0.25 轻微偏移；> 0.25 显著偏移，需要排查客群变化。计算时按基准群体的风险分十分位分箱。
