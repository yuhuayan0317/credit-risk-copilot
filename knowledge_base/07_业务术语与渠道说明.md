# 业务术语与渠道说明

## 获客渠道说明

| 渠道 | 说明 | 客群特点 |
|---|---|---|
| APP自然流量 | 用户主动下载 APP 申请 | 客群质量稳定，是基准渠道 |
| 信息流广告 | 抖音、微信朋友圈等信息流广告投放 | 偏年轻；投放定向策略变化会直接影响客群结构 |
| 合作方导流 | 第三方平台（电商、导流平台）推送用户 | 质量依赖合作方的筛选规则，存在「甩单」风险 |
| 线下门店 | 地推团队线下获客 | 偏年长；受地推 KPI 影响较大 |

## 术语表

| 术语 | 含义 |
|---|---|
| Vintage / Cohort | 按放款月份划分的用户批次。本项目中 loan_month 即 cohort |
| 坏账率 / Bad Rate | 坏用户占比，口径见《指标口径》 |
| 首逾 | 第一期还款即逾期 |
| M1 / M2 / M3+ | 逾期 1 个月 / 2 个月 / 3 个月及以上 |
| 循环信用 | 只还最低还款额，剩余部分计息滚动，pay_status = 0 |
| 准入 | 申请审批环节，决定是否放款 |
| 结构效应（Mix Effect） | 由客群占比变化导致的指标变化 |
| 风险效应（Rate Effect） | 由同一客群自身风险变化导致的指标变化 |
| PSI | 群体稳定性指标，衡量分数分布偏移 |
| AUC / KS | 模型区分度指标 |
| SHAP | 模型可解释性方法，衡量每个特征对预测的贡献 |
| 甩单 | 合作方将自己筛掉的低质量用户推送给下游机构 |
| 溢缴款 | 用户多还的钱，账单金额显示为负数 |

## 分析报告规范

1. 先写结论，再写证据。
2. 每个数字都要标明口径和样本量。
3. 百分比保留 1 位小数，坏账率变化用百分点（pp）表述。
4. 必须写出局限性和数据质量问题。
5. 给出可执行的业务建议，不要只罗列数据。
