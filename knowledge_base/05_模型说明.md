# 违约风险模型说明（Model Card）

## 基本信息

- **模型**：XGBoost 二分类模型
- **目标**：预测用户在表现期内是否违约（is_bad）
- **训练数据**：30,000 个用户，按 64% / 16% / 20% 分为训练集 / 验证集 / 测试集（分层抽样）
- **效果**：测试集 AUC 0.782，KS 0.430
- **产出**：risk_scores 表（违约概率与风险等级）、shap_values 表（每个用户每个特征的 SHAP 贡献）

## 特征列表（27 个）

### 原始特征（23 个）
- 用户属性：credit_limit、sex、education、marriage、age
- 还款状态：pay_status_1 ~ pay_status_6
- 账单金额：bill_amt_1 ~ bill_amt_6
- 还款金额：pay_amt_1 ~ pay_amt_6

### 衍生特征（4 个）
| 特征 | 含义 |
|---|---|
| utilization_1 | 额度使用率 = bill_amt_1 / credit_limit |
| max_pay_status | 近 6 期中最严重的还款状态 = max(pay_status_1..6) |
| n_overdue_months | 近 6 期出现逾期（pay_status ≥ 1）的月份数 |
| repay_ratio_1 | 还款比例 = pay_amt_1 / bill_amt_2（上期账单 ≤ 0 时为空，上限截断为 5） |

注意：channel、loan_month、city_tier **不是模型特征**。模型只看用户本身的属性和行为。所以，如果某渠道的平均风险分上升，说明该渠道引入的用户本身风险更高。

## 风险等级

| 等级 | 规则 |
|---|---|
| 高 | risk_score ≥ 0.5 |
| 中 | 0.25 ≤ risk_score < 0.5 |
| 低 | risk_score < 0.25 |

## SHAP 解读指南

- SHAP 值单位是 log-odds（对数几率）。正值推高违约概率，负值降低违约概率。
- 单个用户：所有特征 SHAP 值之和 + 基准值 = 该用户预测的 log-odds。
- **群体对比归因**：分别计算两个群体每个特征的平均 SHAP，相减后按差值从大到小排序。排名靠前的特征就是「导致群体 A 比群体 B 风险更高」的主要因素。
- 全局重要性：按特征计算 mean(|SHAP|)。本模型全局最重要的特征依次是 pay_status_1、max_pay_status、utilization_1、bill_amt_1、n_overdue_months、credit_limit。
- SHAP 解释的是「模型为什么这么打分」，不直接等于业务因果。

## 已知局限

- 训练数据中没有收入、负债、征信查询等常见风控变量，模型区分度有上限。
- 模型在小样本群体（< 300）上的 AUC 估计不稳定。
- 部分用户 education / marriage 为未定义编码，模型会把这些编码当作普通数值处理。
