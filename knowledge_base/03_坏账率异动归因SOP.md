# 坏账率异动归因分析 SOP

适用场景：业务方反馈「某类用户坏账率突然上升」「某渠道最近风险变差」等问题。

## 第一步：确认口径与问题范围

1. 明确「哪类用户」：对应哪个维度（channel / loan_month / city_tier / 客群标签）。
2. 明确「突然上升」的时间范围和对照期。业务方没有说明时：默认对照期为该群体在异动期之前的月份。
3. 坏账率按 vintage（放款月份 cohort）口径计算，见《指标口径》。

## 第二步：定位异动

1. 先算大盘：全量坏账率按月趋势。如果大盘也同步上升，说明是全局问题，不是某个群体的问题。
2. 按维度下钻：channel × loan_month 交叉表，找出变化 ≥ 3pp 的单元格。
3. 做显著性检验：样本量 ≥ 300 且两比例 z 检验 p < 0.05。
4. 排除干扰维度：确认其他维度（如 city_tier）在异动期没有同步变化。

## 第三步：拆解原因——结构效应 vs 风险效应

坏账率上升有两类原因，必须区分：

- **结构效应（Mix Effect）**：高风险客群的**占比**变大了，但各客群自身的坏账率没变。典型原因：渠道投放策略调整、引入新客群、准入策略放松。
- **风险效应（Rate Effect）**：客群占比没变，但同一客群的坏账率变高了。典型原因：宏观经济、催收策略变化、欺诈攻击。

拆解方法（以客群标签或分层维度为切分）：

```
总变化 = Σ (新占比 - 旧占比) × 旧坏账率      ← 结构效应
       + Σ 新占比 × (新坏账率 - 旧坏账率)    ← 风险效应
```

分别尝试年龄段、额度段、近期逾期状态等维度，哪个维度的结构效应占比最大，就是主要驱动因素。

## 第四步：客群画像与模型验证

1. 对比异动期与对照期的客群画像：平均年龄、平均额度、近期逾期占比、额度使用率等。
2. 对比模型平均风险分：如果模型分也同步上升，说明是可被模型识别的客群变化（结构效应），准入环节应该能拦截。
3. 用 SHAP 做群体归因：分别计算两个群体每个特征的平均 SHAP 值，差值最大的特征就是推高风险的主要因素。
4. 计算 PSI：判断客群分数分布是否显著偏移。

## 第五步：输出结论

结论必须包含：
1. **异动事实**：哪个群体、什么时间、坏账率从多少升到多少（附样本量）。
2. **主要原因**：结构效应还是风险效应，具体是哪个客群/特征驱动，贡献多少。
3. **证据**：分层对比表、SHAP 归因结果。
4. **业务建议**：例如收紧该渠道对特定客群的准入、调整投放定向、提高该客群的模型分阈值。
5. **局限性**：样本量、数据质量问题、未能验证的假设。

## 常见错误

- 只看相对变化不看绝对值：小样本群体从 10% 升到 15%，相对上升 50%，但可能只是随机波动。
- 用月度坏账率的简单平均代替加权坏账率。
- 把相关性当因果：SHAP 解释的是模型如何打分，不等于业务因果，需要结合业务逻辑判断。
- 忽略辛普森悖论：总体坏账率上升，但每个子群体的坏账率都没变，这就是纯结构效应。
