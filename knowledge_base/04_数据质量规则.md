# 数据质量规则

分析前必须检查以下已知数据问题。涉及相关字段时，报告中需说明处理方式。

## 已知问题

### 1. 学历字段存在未定义编码

- education 的有效取值是 1（研究生）、2（本科）、3（高中）、4（其他）。
- 数据中存在 0、5、6 三种**未在数据字典中定义**的编码，合计约 345 个用户（约 1.2%）。
- **处理规则**：按学历分析时，将 0/5/6 合并为「未知」单独列示，**不得**并入任何有效类别，也不得对这些编码给出业务解释。这些用户的坏账率明显偏低，可能是数据录入问题，不宜作为结论依据。

### 2. 婚姻状况字段存在未定义编码

- marriage 的有效取值是 1（已婚）、2（单身）、3（其他）。
- 存在 marriage = 0 的记录（约 54 条），属于未定义编码。
- **处理规则**：单独列为「未知」，并注明样本量过小。

### 3. 账单金额存在负值

- bill_amt_k < 0 表示用户多还款，形成溢缴款，**不是数据错误**。
- 计算额度使用率时保留负值，不要截断为 0；计算平均账单金额时要说明是否包含负值。

### 4. 还款状态 -2 和 0 的含义

- -2 = 当月无消费，0 = 使用循环信用（只还最低还款额），**都不是逾期**。
- 只有 pay_status ≥ 1 才算逾期。常见错误是把 0 当成「正常」、把 -1 当成「逾期」。

### 5. 小样本群体

- 多维交叉（例如 channel × loan_month × city_tier）后，很多单元格的样本量不足 100。
- **处理规则**：样本量 < 100 的群体不报告坏账率结论，只报告「样本不足」；100 ~ 300 之间需加注「仅供参考」。

## 数据质量检查清单

每次分析开始前，确认以下事项：

- [ ] 分析涉及的字段是否存在空值
- [ ] 分类字段是否存在未定义编码
- [ ] 数值字段是否存在超出合理范围的值（如年龄 < 18 或 > 100、额度 ≤ 0）
- [ ] 分组后各组样本量是否足够
- [ ] 比率类结果是否在 [0, 1] 区间
- [ ] 各分组样本量相加是否等于总样本量（避免漏掉 NULL 或未定义编码）
